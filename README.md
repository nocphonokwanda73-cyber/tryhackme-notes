# TryHackMe Cybersecurity Labs

Hands-on labs from TryHackMe, covering offensive security fundamentals, web application weaknesses, and how defenders prevent them.

All labs were completed in TryHackMe's legal, sandboxed environments. Flags, room answers, and account details are covered or left out of the screenshots.

## Labs

* [Offensive Security Intro: Finding Hidden Pages with dirb](https://github.com/nocphonokwanda73-cyber/tryhackme-notes/blob/main/offensive-security-intro/README.md)

## Skills shown

* Working in a virtual attack lab with a browser and terminal
* Running directory enumeration against a web application with `dirb`
* Reading scan output and HTTP response codes (200 and 301)
* Identifying a hidden page with no access control
* Explaining why hiding a page is not the same as securing it
* Describing how a defender would prevent and detect this weakness
* Documenting security work clearly, with screenshots and notes in my own words
